# نظام إدارة الأبنية والكرفانات

نظام شعبة الأبنية والكرفانات — شركة نفط الوسط: سجل الأبنية والكرفانات وغرفها، الإشغال، الكشوفات الدورية، طلبات الصيانة، رموز QR، الخرائط والتقارير.

> **تنبيه:** النظام قيد الإصلاح وغير جاهز للتشغيل الفعلي بعد. راجع تقرير المراجعة وخطة الإصلاح.

## التشغيل

انقر نقراً مزدوجاً على `control-app.bat` ثم:

1. زر **تثبيت + بناء** (مرة واحدة، وبعد كل تحديث).
2. زر **تشغيل النظام**.
3. زر **فتح في المتصفح**.

الإعدادات في ملف `.env` (زر **تعديل الإعدادات**). النسخ الاحتياطية في مجلد `backups` والسجلات في `logs`.

## المتطلبات

- Windows 10/11 أو Windows Server
- Node.js 20 أو أحدث
- PostgreSQL 16 (اختياري حالياً، وإلزامي بعد المرحلة 2 من الخطة)

## البنية

| المسار | المحتوى |
|---|---|
| `src/` | واجهة React |
| `server.ts` | خادم Express |
| `src/db/`، `database/init.sql` | الاتصال بقاعدة البيانات ومخططها |
| `control-app.bat`، `tools\\` ، `script\\` | لوحة التحكم وأدواتها |
| `.data\\store.json` | ملف البيانات |
| `_safety/` | نسخة مضغوطة من الحالة الأصلية (خارج Git) |
