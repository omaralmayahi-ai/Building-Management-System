# دليل تشغيل وتثبيت النظام كتطبيق هاتف مستقل (PWA & APK)
### شركة نفط الوسط - نظام السجل الرقمي الموحد للأصول الهندسية والإنشائية

يوفر هذا الدليل للمهندسين والمشرفين طريقتين لتشغيل النظام على الهواتف المحمولة كـ **تطبيق مستقل تماماً دون شريط المتصفح**:

---

## الطريقة الأولى: التثبيت المباشر بنقرة واحدة (PWA Standalone) - الطريقة الأسرع والأمثل
هذه الطريقة لا تتطلب متجر تطبيقات ولا إعدادات معقدة وتعمل مباشرة على هواتف أندرويد وآيفون:

### لأجهزة أندرويد (Android - Chrome / Edge / Samsung Internet):
1. افتح رابط النظام على المتصفح.
2. ستظهر لك رسالة عائمة في أسفل الشاشة أو زر في أعلى الشاشة: **"تثبيت التطبيق"**.
3. انقر على **"تثبيت الآن على الهاتف"**.
4. اضغط تأكيد **"تثبيت / Install"**.
5. ستتم إضافة أيقونة النظام إلى شاشتك الرئيسية فوراً.
6. عند فتح التطبيق، يعمل في وضع ملء الشاشة (Standalone) تماماً مثل أي تطبيق أندرويد محمل من المتجر دون شريط الروابط أو أزرار المتصفح.

### لأجهزة آبل (iOS - iPhone & iPad):
1. افتح رابط النظام في متصفح **Safari**.
2. اضغط على أيقونة **المشاركة** (مربع به سهم للأعلى ⎋ أسفل الشاشة).
3. اختر من القائمة **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen ⊞)**.
4. اضغط على **"إضافة" (Add)** في الزاوية العلوية.
5. ستظهر الأيقونة على الشاشة الرئيسية وتعمل كنافذة تطبيق مستقلة بدون واجهة متصفح.

---

## الطريقة الثانية: توليد حزمة أندرويد (APK) للإرسال المباشر
إذا كنت بحاجة إلى ملف بصيغة `.apk` لإرساله عبر فلاش ميموري USB أو بلوتوث أو واتساب وتثبيته كملف تقليدي:

### متطلبات التوليد:
- توفر بيئة Node.js (v18+)
- حزمة Bubblewrap CLI الرسمية من Google:
```bash
npm install -g @bubblewrap/cli
```

### خطوات التوليد عبر الأدوات المجهزة في المشروع:
1. توليد الأيقونات المحدثة:
```bash
npm run pwa:assets
```
2. تشغيل سكربت التوليد:
```bash
npm run build:apk
```
أو يدوياً:
```bash
bubblewrap init --manifest=scripts/twa-manifest.json
bubblewrap build
```
3. ستجد ملف `app-release-signed.apk` الناتج، ويمكنك نقله مباشرة إلى أي هاتف أندرويد وتثبيته.

---

## مميزات تشغيل النظام كتطبيق مستقل:
1. **شاشة كاملة بدون متصفح**: لا يظهر شريط العناوين أو أزرار التنقل الخاصة بالمتصفح.
2. **سلاسة وسرعة فائقة**: تخزين محلي للأصول والواجهات عبر Service Worker لسرعة تشغيل لحظية.
3. **جاهزية العمل الميداني**: سهولة مسح رموز QR والتقاط صور الأصول وفحص المواقع من كاميرا الهاتف مباشرة.
